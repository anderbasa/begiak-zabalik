# Begiak zabalik

Archivo fotográfico de Ander: una esfera 3D de fotos que nace de la pupila de un ojo.

- Todo está en `index.html` (sin dependencias ni compilación).
- Las fotos **no** están en este repositorio. Se guardan en el navegador y se sincronizan
  con un repositorio privado aparte (`begiak-zabalik-fotos`) usando una clave de GitHub
  que solo vive en cada aparato.

Para conectar un aparato: Menú → Subir fotos → Sincronización → Conectar.
